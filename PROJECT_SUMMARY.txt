================================================================================
                              QUICK START
================================================================================

1. Build:
   $ make build
   $ go build -o vc main.go

2. Create a migration:
   $ ./vc make migration create_users_table

3. Run migrations:
   $ export DATABASE_URL="postgres://localhost/myapp"
   $ ./vc migrate --dsn $DATABASE_URL

4. Install globally:
   $ make install
   $ vc make migration create_posts_table

================================================================================
                           AVAILABLE COMMANDS
================================================================================

$ ./vc make migration <name>           Create a new migration file
$ ./vc migrate --dsn <dsn>             Run all pending migrations
$ ./vc rollback --dsn <dsn>            Rollback last batch
$ ./vc refresh --dsn <dsn>             Rollback all + re-run
$ ./vc status --dsn <dsn>              Show migration status

Environment flags:
  -e, --env dev|server                 Environment (default: dev)
  -d, --dsn <url>                      Database connection string

Environment variables:
  DATABASE_URL                         PostgreSQL connection string
  VORZELA_ENV                          Environment (dev/server)

================================================================================
                           COMMON WORKFLOWS
================================================================================

Development Workflow:
  1. $ ./vc make migration create_users_table
  2. Edit migrations/dev/timestamp_create_users_table.sql
  3. $ ./vc migrate --dsn $DATABASE_URL
  4. $ ./vc status --dsn $DATABASE_URL
  5. Repeat for more migrations

Testing Workflow:
  1. $ createdb test_db
  2. $ DATABASE_URL=postgres://localhost/test_db ./vc migrate
  3. $ psql test_db -c "\dt"
  4. $ DATABASE_URL=postgres://localhost/test_db ./vc rollback
  5. $ dropdb test_db

Production Deployment:
  1. $ DATABASE_URL="prod_connection_string" ./vc migrate --env server
  2. $ DATABASE_URL="prod_connection_string" ./vc status --env server
  3. Monitor database

Complete Reset (Testing):
  1. $ DATABASE_URL=postgres://localhost/test_db ./vc refresh
  2. All tables dropped and recreated
